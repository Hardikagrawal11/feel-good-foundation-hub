# Feel Good Foundation Hub 🤝

A comprehensive Full-Stack NGO Management Platform designed to streamline social welfare activities, including blood donations, women’s welfare, and community development.

## 🚀 Tech Stack

**Frontend:**
- **React.js** with **TypeScript** (TSX)
- **Tailwind CSS** (Styling)
- **Framer Motion** (Animations)
- **Lucide React** (Icons)

**Backend:**
- **Node.js** & **Express.js**
- **MongoDB Atlas** (NoSQL Database)
- **Mongoose** (ODM)

**Authentication & Tools:**
- **Clerk Auth** (User & Admin Authentication)
- **Vite** (Build Tool)

## ✨ Key Features

- **7 Dedicated Welfare Domains:** Specialized modules for Blood Donation, Women & Girls Welfare, Food Security, Elder Care, etc.
- **Dynamic Campaign Management:** Real-time updates for active NGO programs.
- **Secure Admin Dashboard:** Restricted access via Clerk authentication to manage foundation activities.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop views.
- **Interactive UI:** Smooth transitions and modern "Glassmorphism" design elements.
